# Car Market Trends Analysis Using Car Dekho Data

## Project Overview

This project analyzes the Car Dekho dataset to identify trends and patterns in the used-car market.

## Objectives

- Analyze vehicle selling prices
- Study fuel type distribution
- Compare manual and automatic vehicles
- Analyze seller types
- Study vehicle ownership patterns
- Analyze the relationship between selling price and kilometres driven
- Analyze price differences between present price and selling price

## Dataset

The dataset contains information about:

- Car Name
- Manufacturing Year
- Selling Price
- Present Price
- Kilometres Driven
- Fuel Type
- Seller Type
- Transmission
- Owner

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- GitHub

## Key Findings

- Petrol vehicles form the largest share of the dataset.
- Dealer-sold vehicles are more common than individual sales.
- Manual transmission vehicles are much more common than automatic vehicles.
- Selling prices vary considerably across manufacturing years.
- Higher kilometre readings are generally associated with lower selling prices, although exceptions exist.
- Automatic vehicles have a higher average selling price than manual vehicles in this dataset.
